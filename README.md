# Invoice Intelligence

A browser-based invoice review dashboard that extracts key invoice details from sample text and turns them into clean business summaries.

## Features

- Paste invoice text and extract vendor, total, date, and status
- Dashboard cards for paid, pending, and overdue invoices
- Simple insight panel for cash-flow awareness
- Responsive high-class interface
- Works without backend setup

## How to run

Open `index.html` in a browser.

## Tech stack

- HTML
- CSS
- JavaScript

## Portfolio value

This project demonstrates data extraction thinking, dashboard UI design, and practical business automation.
